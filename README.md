# Orbit: Space Exploration & Mission Tracker

Orbit is a two-page website about space exploration. It shows featured missions, a planet atlas, a launch-history timeline and a mission comparison table. It is built with **semantic HTML**, **CSS Grid**, **Flexbox** and **SASS/SCSS** (Dart Sass). There are no frameworks and no JS libraries.

Assignment 6: *Two-Page Website with CSS Grid, Flexbox, and SASS/SCSS Features*.

---

## Pages

| Page | File | Sections |
| --- | --- | --- |
| **Home** | `index.html` | Sticky navbar · hero with an animated CSS starfield, a CSS-drawn Earth with orbiting moon and satellite, and CTAs · stats strip · Featured Missions card grid · "Mission control" bento grid · newsletter signup · footer |
| **Explore** | `explore.html` | Page header with starfield, breadcrumb, jump links and a clickable solar-system lineup · planet gallery (Saturn is a featured 2 × 2 tile) · alternating launch-history timeline (1957–2022) · mission comparison table · CTA banner back to Home · footer |

Both pages share the same header, footer, theme and components, and link to each other through the navbar, CTAs, footer and in-page anchors (`#missions`, `#planets`, `#timeline`, `#compare`, `#newsletter`).

### UI highlights
- Dark space theme by default (deep navy/violet gradients, neon cyan and violet accents, glass cards, soft glows), plus a **light theme**. The toggle button switches themes and saves the choice in `localStorage`.
- **Animated starfield** drawn only with CSS: three layers of `box-shadow` stars generated by a Sass `@for` loop, drifting at different speeds with a twinkle.
- **Planets as CSS gradient orbs**: radial-gradient shading, a texture layer that slides to look like rotation, a float animation, and rings split into back and front halves so they wrap around the planet.
- Hover lift and glow on cards, a light sweep on buttons, `:focus-visible` rings, a skip link, a scroll-reveal effect where supported (`animation-timeline: view()`), and full `prefers-reduced-motion` support.
- Responsive from 320px phones to wide desktops, using a breakpoint mixin (`sm 576`, `md 768`, `lg 1024`, `xl 1280`).
- Accessibility: landmarks, `aria-labelledby` on sections, `aria-current` in the nav, `aria-expanded` on the menu button, decorative art marked `aria-hidden`, a caption and `scope` on the table, a labelled form input, and colour contrast checked for both themes.

## SASS/SCSS features implemented

Each feature is marked in the source with a `// FEATURE:` comment. To list them all, search the `scss/` folder for `FEATURE:`.

### 1. Variables
Colors, fonts, spacing, radii, z-index, breakpoints and motion are Sass variables and maps.
**File:** `scss/abstracts/_variables.scss`
```scss
$color-cyan: #3be8ff;
$font-display: ('Orbitron', 'Space Grotesk', system-ui, sans-serif);
$spacing-unit: 8px;
$radii: (sm: 8px, md: 14px, lg: 22px, xl: 32px, pill: 999px);
$z-layers: (starfield: 0, base: 1, raised: 10, dropdown: 50, header: 100, skip-link: 999);
```

### 2. CSS custom properties (alongside Sass variables)
Sass variables and functions build the theme values at compile time. They are output as CSS custom properties, which `[data-theme]` swaps at runtime for the light and dark themes.
**File:** `scss/base/_themes.scss`
```scss
$themes: (
  dark:  (bg: $color-void, accent: $color-cyan, glow: alpha($color-cyan, 0.4), ...),
  light: (bg: $color-mist, accent: #006b99, accent-2: shade($color-violet, 30%), ...),
);

:root                    { color-scheme: dark;  @include theme-tokens(map.get($themes, dark)); }
:root[data-theme='light'] { color-scheme: light; @include theme-tokens(map.get($themes, light)); }
```

### 3. Nesting
Components are nested BEM-style with `&__element`, `&--modifier`, `&:hover`, and compound selectors such as `&:hover &__visual .icon`.
**Files:** every component; for example `scss/components/_card.scss`
```scss
.mission-card {
  @extend %card-base;
  &__visual { ... .icon { transition: transform $duration-slow $ease-out; } }
  &:hover &__visual .icon { transform: scale(1.08) rotate(-6deg); }
  &--featured { @include breakpoint(md) { display: grid; ... } }
}
```

### 4. Interpolation
Used in selectors, property names, custom property names and values.
**Files:** `components/_planet.scss`, `abstracts/_mixins.scss`, `base/_themes.scss`, `components/_card.scss`, `base/_typography.scss`
```scss
.planet-#{$name} { --planet-base: #{$base}; }            // dynamic selector + value
border-#{$side}: $width solid $color;                    // dynamic property name
-#{$prefix}-#{$property}: $value;                        // vendor prefixes
--#{$name}: #{$value};                                   // custom property names
.tag--#{$status} { --tag-color: var(--#{$token}); }      // inside var()
h#{$level}, .h#{$level} { font-size: fluid(...); }       // h1–h4
```

### 5. Placeholder selectors (`%` + `@extend`)
Shared styles that only appear in the output where something extends them. Sass then groups the extending selectors into one rule.
**File:** `scss/abstracts/_placeholders.scss`, extended in `_card.scss`, `_stats.scss`, `_timeline.scss`, `_explore.scss`, `_home.scss` and others
```scss
%card-base { position: relative; border-radius: radius(lg); @include glass-effect; ... }
%glow { box-shadow: 0 0 0 1px var(--border-strong), 0 18px 50px -18px var(--glow), ...; }
%visually-hidden { position: absolute !important; width: 1px; height: 1px; ... }
%list-reset, %eyebrow, %gradient-border

.mission-card { @extend %card-base; }
.icon-btn:hover { @extend %glow; }
.sr-only { @extend %visually-hidden; }
```

### 6. Mixins (with arguments, defaults and `@content`)
**File:** `scss/abstracts/_mixins.scss`
```scss
@mixin breakpoint($name, $direction: up) { ... @media (min-width: $width) { @content; } ... }
@mixin flex-center($direction: row, $gap: null) { ... }
@mixin glass-effect($blur: 18px, $strength: normal, $bordered: true) { ... }
@mixin hover-lift($distance: 6px, $glow: var(--glow)) { ... &:hover { transform: translateY(-$distance); } }
@mixin gradient-text($from: var(--accent), $to: var(--accent-2), $angle: 120deg) { ... }
@mixin stagger($count, $step: 0.08s, $start: 0s) { ... }
@mixin planet-texture($type, $shade) { ... }
```
Usage: `@include breakpoint(lg) { grid-template-columns: 1.1fr 0.9fr; }`

### 7. Functions
**File:** `scss/abstracts/_functions.scss`
```scss
@function rem($value, $base: $base-font-size) { @return round-to(math.div($value, $base), 4) * 1rem; }
@function spacing($multiplier)  { @return rem($multiplier * $spacing-unit); }   // spacing(2) → 1rem
@function tint($color, $percent)  { @return -round-channels(color.mix(#fff, $color, $percent)); }
@function shade($color, $percent) { @return -round-channels(color.mix(#000, $color, $percent)); }
@function alpha($color, $opacity) { @return color.change($color, $alpha: $opacity); }
@function z($layer) / radius($size) / weight($name)        // map lookups with @error guards
@function fluid($min, $max, ...)                           // builds a clamp() for fluid type
@function star-field($count, $area)                        // box-shadow star list (see @for)
```

### Additional features (8–14)

| # | Feature | Where | Example |
| --- | --- | --- | --- |
| 8 | **`@use` / `@forward` module system** (no `@import`) | `scss/main.scss`, `scss/abstracts/_index.scss` | `@forward 'variables';` … then `@use '../abstracts' as *;` in each partial |
| 9 | **Maps + `@each`** | `_planet.scss`, `_card.scss`, `_button.scss`, `_hero.scss`, `_home.scss`, `_explore.scss`, `_themes.scss` | `@each $name, $data in $planets { .planet-#{$name} { ... } }` generates 8 planet theme classes; also status tags, button variants, star layers, grid areas |
| 10 | **`@if` / `@else if` / `@else` in mixins** | `_mixins.scss` (`planet-texture`, `breakpoint`, `glass-effect`), `_planet.scss` | `@if $type == bands { ... } @else if $type == craters { ... } @else { background-image: none; }` |
| 11 | **Built-in modules** `sass:math`, `sass:color`, `sass:map`, `sass:list`, `sass:meta` | `_functions.scss`, `_themes.scss`, `_typography.scss` | `math.div`, `math.random`, `math.round`, `color.mix`, `color.adjust`, `color.scale`, `color.change`, `color.channel`, `map.get`, `map.keys`, `list.append`, `list.nth`, `meta.inspect` |
| 12 | **`@for` loops** | `_functions.scss` (`star-field`), `_mixins.scss` (`stagger`) | `@for $i from 1 through $count { $shadows: list.append($shadows, $star, $separator: comma); }` |
| 13 | **`@error` validation** | `_functions.scss`, `_mixins.scss` | `@error 'Unknown breakpoint `#{$name}`. Use one of: #{map.keys($breakpoints)}.';` |
| 14 | **Module-private members** (leading `-`) | `_functions.scss` | `@function -round-channels($color)` is not forwarded to other modules |

## Setup and running

1. **Install Node.js** (LTS, v18 or newer) from <https://nodejs.org>. Check it with:
   ```bash
   node -v
   npm -v
   ```
2. **Install dependencies** (Dart Sass) from the project folder:
   ```bash
   npm install
   ```
3. **Compile SCSS → CSS** once:
   ```bash
   npm run build
   ```
   This runs `sass scss/main.scss css/main.css --style=expanded`.
4. **Watch for changes** while you edit (recompiles on save):
   ```bash
   npm run watch
   ```
5. **Open the site**
   - **VS Code + Live Server (recommended):** install the *Live Server* extension, right-click `index.html` and choose **Open with Live Server**. It reloads automatically when `css/main.css` changes.
   - Or double-click `index.html` to open it straight in a browser. Everything works over `file://`; only the Google Fonts need an internet connection.

> The compiled `css/main.css` is committed, so the site also works without running the build.

## Content note

Mission and planet facts (launch dates, diameters, rotation periods, masses and so on) come from public NASA/ESA information and are rounded for display. Moon counts are shown as "95+", "270+" and "28+" because new moons keep being confirmed. Orbit is a student project and is not affiliated with NASA or ESA. The newsletter form is a UI demo with no backend.
